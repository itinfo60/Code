# QuickSum Overlay
Minimal Android accessibility overlay for addition in an exposed PhonePe amount input.
Type 28, tap +, type 56, tap = to attempt to replace with 84.
Works only where PhonePe permits accessibility reading/editing. Never bypass app protections or automate payments.
Enable "QuickSum amount helper" in Android Accessibility settings. Disable it after use.
Debug APK produced by GitHub Actions at Actions → Build QuickSum APK → Artifacts.
No INTERNET permission. Unverified on real PhonePe devices.
